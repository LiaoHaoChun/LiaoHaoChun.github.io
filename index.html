Projects

CS351 Project0: Two Sum

This project focused on solving the Two Sum problem and practicing the basic software engineering workflow. I learned how to create project documents, organize source code, use GitHub, and follow a clear development process.

This project focused on building a small CSV-based database system. The main functions include reading CSV files, searching records, adding data, and managing simple database operations.

Through this project, I practiced software design, testing, version control, and documentation. I also learned how to divide a project into smaller tasks and improve the program step by step.
